The problem

Farmers sell blind

A tomato that fetches KES 42/kg in Meru fetches 67/kg in Nairobi the same morning. Most smallholders never see the second number, and the broker at the gate knows it.

Weather breaks the run

One night of rain turns a murram road to mud. Produce spoils on a stranded pikipiki, and the price the farmer was promised evaporates.

Advice arrives too late

Extension officers cover thousands of farms. Seasonal warnings (frost above 1,800 m, Fall Armyworm in the hot dry months) reach farmers after the damage.

What Sentinel does · five execution routes, one JSON contract

AMarket arbitrage

Ranks every reachable market by (price × yield) − transit cost, then gates the run through Kenya's seasonal weather matrix before it recommends dispatch.

BFarmer chat

Under-25-word answers in Kiswahili or English, with conversation memory and a hard rule: never invent a number that is not in the live feed.

CAlert broadcast

Turns a telemetry breach or price shock into an SMS-safe farmer message plus a technical operator brief, tiered INFO → WARNING → CRITICAL.

DFarmer onboarding

A five-step profile intake that ends with a climate-risk preview for that farm, that crop, this month.

ELogistics replan

Mid-transit rerouting when a road floods or a vehicle faults — picks the cheapest viable alternative or escalates to the cooperative.

SSoko marketplace

Farmers list surplus; buyers and e-boda riders claim runs. Every listing shows a fair price against the nearest masoko.

  • Gemini-powered LIVE engine with a deterministic guardrail layer: stale prices are never projected, farmer strings never exceed mobile limits, every alert carries a real UUID.
  • Offline-first: a contract-identical mock engine runs the full product with no API key, no network — built for rural Kenya, not a Nairobi office.
  • Kenyan climate matrix encoded: Long Rains, Short Rains, cold-dry frost zones, ASAL drought counties, altitude escalation.
  • Agentic Autopilot chains sense → arbitrage → weather gate → broadcast → mission brief, with a per-step audit trail.
  • Frugal stack: Node, Express, a flat-file store, one system prompt. Runs on a KES 500/month VPS or a Raspberry Pi at a cooperative.
  • SMS-safe by design: every farmer-facing message is under 160 characters and one emoji, ready for Africa's Talking or Safaricom SMS.
  • Docker image, CI pipeline and an HTTP integration suite — deployable to a pilot cooperative this quarter.
  • Next: real price feeds (KAMIS / county market boards), M-PESA settlement on Soko runs, USSD access for feature phones.

Business model · who pays

Cooperatives & aggregators

Per-farmer monthly SaaS for the operator console, alert broadcast and route optimisation. The cooperative already collects levies; Sentinel raises the price they can get.

Soko transaction fee

A small percentage on each delivered run settled through the marketplace, split between platform and rider network.

Data & insurance partners

Anonymised, farm-level risk and yield signals for index insurers, input suppliers and county agriculture offices.

Pre-revenue. Pricing to be validated in the first cooperative pilot. No customer data has been sold or shared.
